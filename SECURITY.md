# Security policy

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/intesarjawad/rowsetta/security/advisories/new).
Do not include credentials, private datasets or exploit details in public issues
or pull requests. Include steps to reproduce using synthetic data where possible.

Development checks use local data and require no model token. Secrets belong
in the local environment. `.env.example` lists configuration without credentials.
